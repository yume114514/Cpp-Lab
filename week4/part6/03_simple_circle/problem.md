# 6-20 SimpleCircle 类

## 题目

实现一个名为 `SimpleCircle` 的简单圆类。其数据成员 `int *itsRadius` 为一个指向其半径值的
指针，存放其半径值。设计对数据成员的各种操作，给出这个类的完整实现并测试这个类。

## 要求

1. 数据成员用指针 `int *itsRadius`，半径值本身放在它指向的动态内存里；
2. 需要构造函数（至少一个带参、一个不带的默认构造）、析构函数 `delete itsRadius`、
   复制构造函数（深拷贝，避免两个对象指向同一块内存）；
3. 操作至少要能设半径、取半径、算面积、算周长、输出；
4. 在 `main` 里造对象、拷贝对象、改值、观察输出，验证两个对象互不影响。
