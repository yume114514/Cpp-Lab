## 3-7 两个数相除的函数

**题目**：完成函数，参数为两个 unsigned short int 型数，返回值为第一个参数除以第二个参数的结果，数据类型为 short int；如果第二个参数为 0，则返回值为 -1。在主程序中实现输入输出。

**思路**：先判断除数是否为 0，是则返回 -1，否则返回两数之商。形参与返回值的类型不同，由编译器按赋值规则完成转换。

| 输入 a b | 输出 |
| --- | --- |
| 10 3 | 3 |
| 7 0 | -1 |
| 100 7 | 14 |

## 3-9 判断质数

**题目**：编写函数判别一个整数是否是质数？要求在主函数中输入输出。

**思路**：试除法，从 2 试到 sqrt(n)，只要有一个因子就不是质数；n <= 1 直接判为非质数。

| 输入 | 输出 |
| --- | --- |
| 17 | YES |
| 9 | NO |
| 1 | NO |

## 3-10 最大公约数与最小公倍数

**题目**：编写函数求两个整数的最大公约数和最小公倍数。要求两个整数以及结果在主函数中输入输出。

**思路**：用辗转相除（欧几里得算法）求最大公约数，再用 a / gcd(a, b) * b 求最小公倍数，先除后乘可以避免 a * b 溢出。

| 输入 n m | 输出 gcd lcm |
| --- | --- |
| 12 18 | 6 36 |
| 7 5 | 1 35 |

## 3-13 递归求 Fibonacci 级数

**题目**：用递归的方法编写函数求 Fibonacci 级数，公式为 F(n)=F(n-1)+F(n-2) (n>2)，F(1)=F(2)=1。

**思路**：按公式直接写成递归，终止条件是 n=1 或 n=2。为避免重复计算，用一个数组把算过的项存起来，再次使用时直接返回数组中已有的值。

| 输入 n | 输出 F(n) |
| --- | --- |
| 10 | 55 |
| 20 | 6765 |

## 3-15 递归函数 getPower（重载）

**题目**：编写递归函数 getPower 计算 x^y，针对整型和实型实现两个重载版本：`int getPower(int x, int y)`（整型版本，当 y<0 时返回 0）、`double getPower(double x, int y)`（实型版本）。在主程序中分别输入整数 a 和实数 b 作为底数、整数 m 作为指数，输出 a^m 和 b^m。

**思路**：两个函数同名，靠参数类型区分。整型版本遇 y<0 直接返回 0；实型版本遇 y<0 时用 1/getPower(x, -y) 处理负指数，因此能表示小数结果。

| 输入 a b m | 输出 a^m b^m |
| --- | --- |
| 2 1.5 3 | 8 3.375 |
| 2 2.0 -2 | 0 0.25 |

**思考**：若希望计算 a^m 时得到实型结果，应显式地把整型底数转换为 double 再调用，即 `getPower((double)a, m)`，
这样会匹配到 double 版本，m<0 时也能得到正确结果（上表第二行中，整型版本按约定返回 0，实型版本返回 0.25）。
